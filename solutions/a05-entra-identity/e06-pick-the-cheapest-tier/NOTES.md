# Notes

**Why it is correct.** Reset is P1, dynamic groups are P1, PIM is P2, password change is Free. Each claim is on the Learn page the README names.

**Numbers / SKUs.** Free / P1 / P2 only. Microsoft 365 Business Standard also covers cloud SSPR reset; it is not one of the three answers.

**Alternatives.** Entra ID Governance also covers PIM; the exercise answers are Free, P1, or P2.

**The usual mistake.** Treating forgotten-password SSPR as Free because password *change* is Free, or starting a P1/P2 trial in the Default Directory.
